## 数据集摘要
本数据集为现场实拍工地设备目标检测数据集，包含起重机、挖掘机、拖拉机、卡车、其他五类工程设备，覆盖施工场景全貌。图片清晰完整，附带时间戳标注记录拍摄日期，多帧展示工地现场全貌，支持YOLO目标检测格式标注。适合智慧工地设备识别、施工车辆监管、工程设备自动统计等场景的算法训练与科研毕设使用。
